# NeuraX AI 🚀

NeuraX AI is a futuristic AI SaaS platform.

## Features (planned)
- AI chat system (ChatGPT-style)
- Engineering assistant mode
- Research assistant mode
- AI project builder
- File upload + document analysis
- Subscription system

## Tech Stack
- Frontend: Next.js
- Backend: Express.js
- Database: PostgreSQL + Prisma
- AI: OpenAI + Claude
